# Project Management Practice Lab

An interactive project-management case study demonstrating how an expense-reporting automation project can be planned, monitored and delivered using Agile, Scrum and structured project-management practices.

## Live Demo

[Open the Interactive Project Management Lab](https://aliza-project-management-lab.mythicpeony8193.chatgpt.site)

## Project Background

This project is based on a real expense-management workflow involving receipt collection, expense categorisation, automated Google Sheets updates and management reporting.

I developed this interactive case study to demonstrate how the same operational initiative could be managed through a formal project-management framework.

## Project Objective

To design and manage an expense-reporting automation project that improves receipt collection, data accuracy, expense categorisation and reporting visibility while reducing repetitive manual work.

## What the Project Demonstrates

- Project scope and deliverables
- Agile and Scrum fundamentals

- Tasks, owners, priorities and due dates
- Milestones and dependencies
- Risk and issue registers
- Stakeholder mapping
- Project timelines and Gantt charts
- Budget and resource tracking
- Change-control procedures
- Meeting minutes and action logs
- Weekly project-status reporting
- Escalation and decision tracking

## Interactive Features

- Move tasks between Scrum-board stages
- Add new project tasks
- Record and evaluate project risks
- Monitor project progress and budget
- Review milestones and dependencies
- Approve or reject change requests
- Maintain meeting notes and action items
- Generate weekly status reports
- Export project information as JSON
- Save changes locally in the browser

## My Role

I defined the project objective, structured the scope and deliverables, created the backlog, mapped dependencies and stakeholders, documented risks, designed the project controls and built the interactive application.

The underlying expense-automation experience came from my professional work with Google Sheets, Apps Script, receipt processing, expense categorisation and reporting dashboards.

## Project-Management Approach

The project demonstrates a hybrid approach:

- **Agile/Scrum** for backlog management, short delivery cycles and continuous improvement.
- **Waterfall planning** for clearly defined implementation, testing and launch milestones.
- **Traditional project controls** for budgets, risks, stakeholders, changes and reporting.

## How to Run Locally

1. Download or clone the repository.
2. Open the `dist` folder.
3. Open `index.html` in a web browser.

No installation or external database is required.
